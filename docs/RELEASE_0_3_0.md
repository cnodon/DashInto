# Clash Dash 0.3.0：核心使用流程闭环

日期：2026-10-25。构建号：3。个人 iPhone 开发签名版本，不是 App Store 发布。

## 使用方式

1. 打开「订阅」，添加地址、文件或节点内容。
2. 导入预览默认显示识别到的线路、使用方式；详细兼容说明可以展开。
3. 点「使用并连接」即可使用本次导入的订阅，回到连接页，并按需要完成系统 VPN 授权。已连接时按钮明确写「切换并重连」。
4. 「仅保存」只入库，不改变现有选择或连接。保存后可直接点击订阅卡片上的「使用并连接」。
5. 线路有默认选择，不必先手动选节点。断开时可在线路页预选；选择保存在本机，重启 App 仍保留。
6. 首页区分系统隧道、核心响应和实际网络检查。网络检查通过仅指 Apple 与 Cloudflare 的 HTTPS 目标在检查时可达。

复杂 Clash 配置保留原来的用途分组和规则；首页显示「按不同用途分流」，不再任取第一个局部组冒充全局线路。测速需要已连接，离线选线路不需要先测速。

## 修复的真实连接故障

真机复现了内部 Unix socket 路径超长：原来的 BasePath 在 `Runtime/<profile UUID>/<generation UUID>`，实际 socket 路径长达 176 字节，超过 Darwin 的 103 字节限制。配置可以导入、签名也正确，但核心在启动内部控制通道时失败。

修复后，核心 BasePath 使用 App Group 下的短目录 `Core`；工作目录仍按配置版本隔离。启动前检查 socket 路径字节数。回归测试使用与真实 iOS 相同长度的容器路径，验证旧路径超限、新路径满足限制。未关闭 TLS 校验或简化用户规则来绕开故障。

## 代码中的状态约束

- `ProfileStore.commitImport` 返回确切 profile ID、generation 和索引；不自动选择第一份导入。
- `ConnectionCoordinator` 独立持有连接任务，关闭导入 sheet 不会取消连接；同一时间只进行一个启停事务。
- 取消、超时与网络检查结果受 attempt/session 保护；快照及 IPC 回执验证 session、generation 与状态 epoch。
- 重新加载系统配置不能覆盖正在启动的 manager。授权保存完成后再次检查取消状态，防止用户取消后延迟启动。
- 扩展启动前错误通过受保护的共享文件回传，并带 startup ID 和 generation，避免旧连接错误污染新尝试。
- 运行页按实际运行的 generation 显示摘要；订阅更新显示「更新已保存，重新连接后使用」。多次更新仍保留运行版本的摘要与加密内容。
- 连接后选择线路先由核心读回确认，再持久化；离线选择保存为下次偏好。
- Release 移除直连诊断样本导入入口。已有配置不删除；仅直连文件明确标注，不伪装成代理线路。

## 验证证据

### 物理 iPhone

设备：已连接的 iPhone 15 Pro Max。使用用户授权的本地订阅，在 App 内完成下载、核心解析、资源准备和连接流程。订阅识别为 36 条静态线路、31 个策略组、6454 条 iOS 规则及 1 份地理数据库。

通过项：

- 本次订阅与实际运行的 generation 一致。
- 默认规则模式的两个 HTTPS 检查通过。
- 系统 Packet Tunnel 已建立，核心 IPC 返回真实运行状态。
- AnyTLS 线路全局选择、HTTPS 204 / 200 请求通过。
- 核心计数观测到测试请求对应的流量增长。
- 系统 UDP DNS、指定 AnyTLS 线路的独立无缓存 UDP DNS 通过。
- 节点延迟测得 124 ms（单次测量，不代表长期性能）。
- 切回规则模式、断开、断开后的网络恢复、再次连接和 HTTPS 均通过。
- 采样核心内存峰值 16,729,832 字节；不是长时间或全设备内存上限。

脱敏报告：[iphone-0.3.0.json](validation/iphone-0.3.0.json)。该报告来自显式启用的 Debug 实验入口，调用产品实际导入器、存储、连接协调器与扩展，不是模拟连接。Release 不包含该实验入口。Release 界面验收也已通过：普通连接按钮 → 两个网络检查通过 → 线路页 → 断开恢复未连接。结果包为 `.build/UXClosure/ReleaseUIRetest.xcresult`，截图为 [Release 真机连接页](screenshots/iphone-connected-0.3.0.png)。

### 自动化与构建

- 28 项共享包测试通过，覆盖导入、存储、取消、错误恢复、session/generation、路径边界和运行版本保留。
- 3 条模拟器端到端用例通过：使用并连接明确选择本次订阅；仅保存不改变选择；离线选择与重启持久化；不合法 URL 保留输入；模拟器明确报无法建立 VPN。
- Release App 与 Extension 签名、VPN、App Group、Keychain 权限检查通过。
- UI 自动化只输入公开合成样本。真机订阅通过权限受限的一次性文件传递，读取后删除；地址和密码未写入源码、启动参数或截图。

模拟器最后一轮曾因未等待 sheet 关闭而发生测试定位失败，修正等待后单独复测通过；另两条用例在同一版代码上通过。首轮 Release UI 测试遇到 Xcode 调试启动器错误；正常启动 App 后改为附加到运行实例，界面测试通过。以上工具失败保留在日志中。

汇总见 [release-0.3.0.json](validation/release-0.3.0.json)。详细日志在本机 `.build/UXClosure/`。先前 macOS 47 项导入与 12 组协议互操作结果继续保留，其测试平台仍标为 macOS。

## 本版边界

- 尚未完成长时间锁屏、Wi-Fi/蜂窝切换和耗电稳定性验收。
- 本轮真机代理 UDP 实测为 AnyTLS，不推导为所有机场节点都可用。此前机场 Trojan UDP 未通过的结论仍保留。
- provider 节点计数在新导入时读取；依赖远程 provider 的具体线路在连接后展开，已有旧配置会在更新后补充摘要。
- 不包含自动连接、后台订阅刷新、云同步、付费或公开发布。
