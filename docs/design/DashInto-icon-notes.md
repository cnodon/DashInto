# DashInto 图标

当前版本：Di 融合动感版，2026-10-25。生成方式为内置 imagegen 编辑，以 D+i 共用笔画版本为参考，按用户要求增强干练、迅速的感觉。完整生成图保存在 `DashInto-icon-di-speed-original.png`；App 资源为 `ClashDashApp/Assets.xcassets/AppIcon.appiconset/AppIcon.png`。完整最终提示词见 `DashInto-icon-di-speed-prompt.txt`。

设计输入：纯黑实底与白色主形，保留 D 的圆润外轮廓；将下方笔画向上延伸为小写 i 的竖笔，共用一个形体，在开口处用一个圆点完成 i。仅两个白色组成部分，扩大留白，去掉多条速度线，整体向右前倾，顶部起笔采用干净斜切，收紧左下转角；i 的圆点演化为顺着同一倾角的小圆角块，通过轮廓增强速度感。无阴影、渐变、3D 或边框，由 iOS 裁切外圆角。

生成图 1280 × 1280；只做技术性缩放到 1024 × 1024，PNG 无透明通道。上一版柔和 Di 方案保存在 `DashInto-icon-di-v2.png`。最初的多条流线图标保存在 `DashInto-icon-v1.png`，最早生成原图保存在 `DashInto-icon-original.png`，便于回看。
